# Contributing to Roadmap Items

Detailed guide for working on larger roadmap features.

## Overview

Roadmap items are significant features that require careful planning and often involve multiple PRs.

## Process

### 1. Claim the Work

Comment on the issue indicating your interest:

```
I'd like to work on this feature. Here's my proposed approach:

1. [Step 1]
2. [Step 2]
3. [Step 3]

I plan to break this into the following PRs:
- PR 1: Core functionality
- PR 2: UI integration
- PR 3: Tests and polish

Estimated timeline: 2-3 weeks

Feedback welcome!
```

### 2. Get Alignment

Wait for maintainer feedback before starting implementation.

### 3. Break Into PRs

Each PR should:
- Be independently reviewable (< 500 lines ideally)
- Have clear purpose
- Include tests
- Build on previous PRs

### 4. Iterate

Respond to feedback and refine.

## Tips for Success

- Start small and iterate
- Communicate early and often
- Keep PRs focused
- Add comprehensive tests
- Document your changes
