# Contributing to Roadmap Features

Guide for working on larger features from Zed's roadmap.

## Overview

Roadmap features are larger initiatives that require planning, design discussions, and coordinated implementation. This directory provides templates and guidance for contributing to these features.

## Before Starting

### 1. Check for Existing Work

Search GitHub for:
- Open PRs
- Related issues
- Design discussions

### 2. Discuss Your Approach

For large features:
- Open a discussion or comment on the issue
- Propose your implementation approach
- Get feedback before investing significant time

### 3. Break Down the Work

Large features should be broken into:
- Smaller, independent PRs
- Incremental improvements
- Testable milestones

## Working on Roadmap Features

### Step 1: Research

- Understand the feature requirements
- Review similar implementations in other editors
- Identify affected crates

### Step 2: Design

- Sketch the architecture
- Identify API changes
- Plan UI/UX

### Step 3: Implementation

- Start with minimal viable implementation
- Add tests incrementally
- Keep PRs focused and reviewable

### Step 4: Iteration

- Respond to feedback
- Refine implementation
- Add polish
